轻松配钞：薪资分配策略工具（Money Distribute AI）

批量计算发薪配钞方案，自动校验余数与贪心拆分结果。

访问上线版本 ↗查看 GitHub ↗

一款面向高规则密度场景的薪资分配策略工具。相比强调“贪心算法”，它更体现我如何把重复、易错的流程做成双端可用的小产品。

规则执行
贪心拆分 + 余数校验
输入方式
单笔 + Excel 批量
输出形式
固定列导出
交付终端
Web + 小程序

为什么要做这件事

使用场景适用于发薪、现金分发、批量换钞与柜台场景。

核心问题人工拆分慢、余数易错、批量名单校对成本高。

负责范围我负责需求梳理、拆分规则定义、批量导入导出流程设计、异常校验策略，以及网页端与小程序端口径统一。

产品判断我优先保证“算得对、导得出、能批量复核”，而不是堆叠复杂交互，确保下游流程稳定接住输出结果。

把规则做成路径

01勾选面额
02贪心拆分
03余数校验
04批量导出

勾选可用面额 → 按从大到小贪心拆分 → 校验余数与异常金额 → 一键导出固定列顺序。
