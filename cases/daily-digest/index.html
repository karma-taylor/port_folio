+ 速览

基于 Agent + RAG 思路的自动化资讯订阅平台，重点在于把多源信息稳定加工成可订阅、可复用、可按时送达的内容产品。

01背景与用户

使用场景适用于需要晨报、晚报、行业订阅和内部情报汇总的团队。

核心问题多源信息碎片化，人工摘要成本高，缺少稳定送达。

本轮范围以“每天按时得到可消费的主题摘要”为范围，梳理信息源、主题、时区与订阅输出；不在本轮解决深度研判和个性化推荐。

为什么做我关注的是把“读很多来源”变成“稳定收到一份结构化结果”，而不是单纯做信息抓取。

典型用户产品／运营负责人（脱敏角色）

情境
每天工作开始前，需要获取按主题和时区整理的行业摘要。
需要
在一个入口完成重点信息判断，而非在多个来源间反复切换。
风险
重复阅读与手工汇总会挤占当天的判断和协同时间。

02方案与取舍

我负责的部分我负责订阅场景梳理、主题分栏策略、摘要结构定义、定时推送机制以及结果验收口径。

关键取舍我优先输出可消费的结构化日报，而不是一次性长文总结，先保证按时送达与可复用，再逐步增强深度分析能力。

方案路径

02主题分栏
03结构化摘要
04邮件推送
