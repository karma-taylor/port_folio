为什么要做这件事

使用场景适用于报销、差旅、柜台咨询和跨境结算场景。

核心问题汇率来源不一致、人工换算易错、弱网场景仍需出数。

负责范围我负责场景拆解、汇率口径定义、换算纠偏规则、异常提示设计，以及缓存与弱网策略验证。

产品判断我不做“黑盒换算结果”，而是明确展示所用来源和汇率口径，优先保证结果可复核与可交付。

输入币种和金额 → 选择参考汇率 → 方向互换时做倒数修正 → 输出结果与口径说明。
